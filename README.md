# Backend de Gestion de Drones

Backend de Module en Java pour la gestion d'un drone,
offrant des calculs de consommation de batterie,
d'autonomie de vol, de suivi de distance et de planification de maintenance.

Ce service s'intègre avec une interface graphique Swing via
une couche de connexion pour permettre à l'utilisateur de faire
ces calculs de façon plus simple.
